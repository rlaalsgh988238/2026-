# 🦽 변(便)수없길

> **휠체어 이용자의 무장애 여행을 위한 배리어프리 화장실 동선 검증 플래너**

여행 중 겪을 수 있는 화장실 확보의 불안감을 덜어드리고자 기획된 안드로이드 애플리케이션입니다.
단순한 위치 정보 제공을 넘어, 사용자의 이동 동선을 기준으로 화장실 공백 구간을 사전에 파악하고 유연하게 대비할 수 있도록 돕습니다.

## 💡 주요 기능

### 1. 동선 기반 위험도 시각화 (사전 여행 플래너)
- 사용자가 설정한 여행 코스를 바탕으로 화장실 간의 거리와 접근성을 분석합니다.
- 화장실 공백 구간(위험도)을 지도 위에 색상으로 직관적으로 표시하여, 여행 전 안전한 동선을 계획할 수 있도록 지원합니다.

### 2. 위기 대응 '패닉 버튼'
- 예기치 못한 생리적 위기 상황 발생 시, 터치 한 번으로 현재 위치에서 가장 가까운 이용 가능한 장애인 화장실을 탐색합니다.
- 내비게이션 앱과 연동되어 신속하게 대안 경로를 안내합니다.

### 3. 맞춤형 배리어프리 정보 제공
- 휠체어 접근이 가능한 화장실의 위치 및 이용 가능 여부 정보를 제공하여, 현장에서 겪을 수 있는 변수를 줄입니다.

## 🛠 기술 스택 (Tech Stack)

- **Network:** Retrofit2, OkHttp
